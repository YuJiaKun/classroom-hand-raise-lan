# 局域网课堂举手互动工具 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个 Windows 桌面版局域网课堂互动工具，包含老师端和学生端两个 exe，支持举手、反馈、文字提问和截图上传。

**Architecture:** 老师端运行 TCP 服务并维护课堂状态，学生端作为 TCP 客户端连接老师端；UDP 广播用于学生端自动发现课堂，发现失败时允许手动输入老师 IP。共享模块负责消息协议、课堂状态、图片压缩、文件保存和通用配置，UI 层只通过服务层接口收发事件。

**Tech Stack:** Python 3.11、PySide6、标准库 `socket`/`threading`、Pillow、PyInstaller、`unittest`。

---

## 1. 产品范围

第一版只做固定教室、局域网、本地桌面长期使用场景，不做公网访问、账号登录、云同步、浏览器版、移动端和任意文件上传。

老师端能力：
- 启动课堂服务，显示本机连接地址和课堂状态。
- 查看在线学生列表、举手队列、快捷反馈统计。
- 接收学生“不懂点”文字和截图，展示未读数量、文字摘要、截图缩略图。
- 点击问题查看完整文字和大图，并可标记已处理。
- 本地保存课堂事件记录和学生上传截图，便于课后复盘。

学生端能力：
- 自动发现老师端，也支持手动输入老师 IP。
- 填写姓名后连接课堂。
- 支持举手、取消举手、快捷反馈。
- 支持输入“不懂点”文字、选择或粘贴已有截图图片、预览截图、确认上传。
- 离线或连接异常时禁用上传，并提示“未连接老师端，请重新连接”。

模块职责：
- `shared.protocol`：长度前缀 JSON 帧编码、解码、读写流。
- `shared.classroom`：学生在线状态、举手队列、反馈统计、帮助请求收件箱。
- `shared.image_tools`：截图压缩、尺寸限制、base64 编码和上传字段生成。
- `shared.storage`：课堂事件 JSONL 保存、截图落盘、会话目录管理。
- `shared.discovery`：UDP 广播和监听，提供老师端自动发现。
- `teacher.server`：TCP 服务端、连接管理、消息分发、课堂状态更新。
- `teacher.ui`：老师端 PySide6 控制台界面。
- `student.client`：TCP 客户端、自动重连、消息发送、连接状态通知。
- `student.ui`：学生端 PySide6 操作界面和截图预览。

## 3. 网络与协议

TCP 消息使用长度前缀 JSON 帧：

```text
4 字节大端 unsigned int 长度 + UTF-8 JSON payload
```

消息类型：
- `join`：学生加入课堂，字段为 `name`、`client_version`。
- `join_ack`：老师端返回学生 ID、课堂名称、服务器时间。
- `raise_hand`：学生举手。
- `lower_hand`：学生取消举手。
- `feedback`：学生发送快捷反馈，例如“已懂”“不懂”“太快”“太慢”。
- `help_request`：学生上传不懂点文字和可选截图。
- `heartbeat`：连接保活。
- `leave`：学生主动离开。
- `error`：老师端返回错误说明。

`help_request` 字段：

```json
{
  "type": "help_request",
  "student_id": "stu-xxxx",
  "text": "这里的循环条件没看懂",
  "screenshot": "base64 jpeg or null",
  "image_format": "jpeg",
  "width": 1280,
  "height": 720
}
```

截图限制：
- 只支持截图，不支持任意文件上传。
- 学生端发送前必须预览确认。
- 默认压缩为 JPEG。
- 最长边限制为 1600px。
- 单次截图上传建议不超过 2MB。
- 如果没有文字且没有截图，禁止发送。

UDP 自动发现：
- 老师端每 2 秒向局域网广播课堂信息。
- 学生端监听广播并展示可连接课堂。
- 自动发现失败时，学生端保留手动 IP 输入入口。

- 老师端可将问题标记为已处理。
- 老师端关闭后，学生端显示断线状态，并禁用上传。
- 打包后的 exe 能在无 Python 环境的 Windows 10/11 机器上运行。

## 6. 默认约束

- 普通界面文案、交互提示、说明文档默认使用简体中文。
- 不做公网穿透，不依赖外部服务器。
- 不做任意文件上传，避免课堂环境下的文件安全和体积管理问题。
- 老师端本地保存数据，不默认上传云端。
- 优先保证课堂中稳定、低打扰、可恢复；高级统计和复杂权限放到后续版本。
