# 使用说明

## 老师端

1. 双击运行 `教师端.exe`，或开发环境中运行：

   ```powershell
   python -m classroom_hand_raise.teacher.app
   ```

2. 可先修改“课堂名称”和“端口”，点击“保存设置”。下次打开老师端会自动沿用上次设置。
3. 点击“启动课堂”。
4. 把界面上显示的“推荐连接地址”告诉学生。如果学生端能自动发现课堂，可以不用手动输入。
5. 课堂中可查看：
   - 在线学生
   - 举手队列
   - 反馈统计
   - 课堂提醒
   - 问题收件箱
6. 学生上传“不懂点”后，老师端右侧会出现未读问题。双击问题可查看完整文字和截图。
7. 在问题详情中填写“回复学生”，点击“发送回复”后，学生端会收到老师回复。
8. 处理完问题后，可点击“标记已处理”。
9. 换新班级时，点击“新班级清空”，确认后会先自动备份旧课堂记录，再清空当前课堂列表；课堂名称和端口设置会保留。

学生举手、重点反馈和提交不懂点会在老师端顶部显示匿名提醒，并在窗口角落弹出非阻塞匿名弹窗提醒；投屏时不会暴露学生姓名。老师端管理界面的举手队列和课堂提醒列表可查看具体学生。
学生短暂断线时会在老师端学生表中显示为“离线”，不会立刻从列表消失；使用同一台电脑重连后会恢复为“在线”。
教师端和学生端都禁止多开；如果已经运行，再次打开会提示“已经在运行，请不要重复打开”，避免端口冲突、重复连接或同一名学生显示成多个人。

## 学生端

1. 双击运行 `学生端.exe`，或开发环境中运行：

   ```powershell
   python -m classroom_hand_raise.student.app
   ```

2. 输入姓名。学生端会自动记住姓名、上次老师 IP 和端口，下次打开会自动填充。
3. 优先选择自动发现到的课堂；如果没有发现，手动输入老师端显示的 IP 和端口。
4. 点击“连接老师端”。
5. 连接后可使用：
   - “举手提问”
   - “取消举手”
   - “可以继续 / 我没听懂 / 讲慢一点 / 请再讲一遍”
   - “上传不懂点”
   - “老师回复”

学生端有互动频率限制：举手提问 10 秒冷却，四个课堂反馈按钮共享 5 秒冷却，发送不懂点 30 秒冷却。冷却期间按钮会显示“请稍候 X 秒”；如果短时间重复点击，老师端会拦截，避免误点和刷屏。

## 上传不懂点

学生端支持两种内容：

- 文字说明：描述哪里没听懂。
- 截图图片：先用 Windows 截图工具、QQ/微信截图等方式截图，再点击“选择截图图片”上传，或复制截图后点击“粘贴截图”。

截图会自动压缩为 JPEG，最长边限制为 1600px，单次上传建议不超过 2MB。当前版本只支持 `png`、`jpg`、`jpeg`、`webp` 图片，不支持任意文件上传。

## 老师回复

- 老师在问题详情中发送回复后，在线学生端会在“老师回复”区域看到答案。
- 如果学生暂时离线，只要使用同一台电脑重新连接本课堂，学生端会补收未读回复。
- 老师回复只针对学生提交的某一条问题，不是全班公告。

## 数据保存位置

老师端会在本地保存课堂记录：

```text
data/class_sessions/<session_id>/
  events.jsonl
  uploads/
data/class_session_archives/
  <timestamp>-before-clear.zip
```

`events.jsonl` 保存课堂事件；`uploads/` 保存学生上传的截图。
点击“新班级清空”前，老师端会把 `class_sessions/` 自动归档到 `class_session_archives/` 下的 zip 文件。如果归档失败，系统不会清空旧课堂数据。

老师端设置会保存在当前 Windows 用户的本地应用配置目录，例如：

```text
%LOCALAPPDATA%\ClassroomHandRaise\teacher_settings.json
```

## 防火墙提示

如果学生端无法连接老师端：

1. 确认老师和学生电脑在同一个局域网。
2. 确认老师端已点击“启动课堂”。
3. 在学生端手动输入老师端显示的 IP 和端口。
4. Windows 防火墙弹窗出现时，选择允许专用网络访问。
5. 如果仍无法连接，请在老师电脑防火墙中允许 `教师端.exe` 的 TCP/UDP 局域网通信。

## 教室试用检查清单

正式上课前，建议用 3-5 台学生电脑做一次 5 分钟试用：

- 老师端点击“启动课堂”，确认顶部能看到在线人数、举手人数和未读问题数。
- 老师端修改课堂名称或端口后点击“保存设置”，关闭再打开确认设置仍然保留。
- 学生端优先选择自动发现到的课堂；发现失败时，手动输入老师端显示的 IP 和端口。
- 每台学生电脑分别测试“举手”“取消举手”和一个快捷反馈。
- 至少一台学生电脑发送文字不懂点，老师端确认问题收件箱出现未读记录。
- 至少一台学生电脑发送截图不懂点，老师端确认能看到缩略图，并可打开详情查看大图。
- 老师端在问题详情中发送一条回复，学生端确认“老师回复”区域能看到答案。
- 老师端将问题标记为已处理，确认未读数量减少。
- 老师端点击“导出课堂记录”，确认能得到 JSON 文件。
- 老师端点击“新班级清空”，确认生成归档 zip，并确认在线学生、举手队列、问题收件箱和当前课堂记录被清空。
- 老师端停止课堂后，学生端应能看到断线或发送失败提示。
- 重复打开教师端和学生端时，应看到禁止多开的中文提示。
- 学生举手、重点反馈和提交不懂点时，老师端应出现匿名弹窗提醒。

## 打包命令

开发环境中可使用以下命令生成 exe：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_teacher.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build_student.ps1
```

如果 PowerShell 脚本被策略拦截，也可以执行：

```bat
scripts\build_teacher.cmd
scripts\build_student.cmd
```

打包后可执行以下命令检查 exe 是否能正常加载入口：

```powershell
.\dist\教师端\教师端.exe --smoke-test
.\dist\学生端\学生端.exe --smoke-test
```
