# 局域网课堂举手互动工具完整使用说明

## 适用场景

本工具适合固定教室、机房或同一局域网内的课堂互动。老师端负责启动课堂服务，学生端连接老师端后可以举手提问、发送课堂反馈、上传不懂点截图，并接收老师回复。

## 老师端使用

1. 双击 `教师端.exe`。
2. 根据需要修改“课堂名称”和“端口”，点击“保存设置”。下次打开会自动沿用这些设置。
3. 点击“启动课堂”。
4. 把界面显示的“推荐连接地址”告诉学生。学生端能自动发现时，可以不用手动输入。
5. 课堂中重点看四个区域：
   - 在线学生：查看谁已连接；学生短暂断线时会显示为“离线”，不会立刻从列表消失。
   - 举手队列：查看谁举手提问，按举手先后排序。
   - 反馈统计：查看“可以继续”“我没听懂”“讲慢一点”“请再讲一遍”的人数。
   - 问题收件箱：查看学生上传的不懂点文字和截图。
6. 如果学生举手、发送重点反馈或提交不懂点，老师端会在窗口角落弹出非阻塞匿名弹窗提醒，老师不用点“确定”，弹窗会自动消失。

## 匿名提醒与管理界面

- 学生点击“举手提问”后，老师端顶部会出现匿名提醒：“有学生举手提问”。
- 学生点击“讲慢一点”“请再讲一遍”“我没听懂”后，老师端顶部会出现匿名提醒，例如“有学生反馈：讲慢一点”。
- 学生提交不懂点后，老师端会提示“有学生提交不懂点”。
- 弹窗提醒和顶部匿名提醒不会显示学生姓名，避免在投屏时暴露学生。
- 弹窗提醒是非阻塞小弹窗，最多同时保留 3 条，约 6 秒后自动消失。
- 老师端管理界面可以查看具体学生：举手队列、在线学生表格、课堂提醒列表都会显示姓名，方便老师点名处理。
- “课堂提醒”列表保留最近提醒，便于老师回看是谁举手或反馈。

## 禁止多开

- 教师端禁止多开。如果教师端已经在运行，再次打开会提示“教师端已经在运行，请不要重复打开。”，避免端口冲突和课堂控制台混乱。
- 学生端禁止多开。如果学生端已经在运行，再次打开会提示“学生端已经在运行，请不要重复打开。”，避免同一台学生电脑重复连接成多个人。
- 异常退出后留下的旧锁会自动清理；正常关闭后下次可以直接打开。

## 学生端使用

1. 双击 `学生端.exe`。
2. 第一次使用时输入姓名；下次打开会自动填充姓名、老师 IP 和端口。
3. 优先选择自动发现到的课堂；如果没有发现，手动输入老师端显示的 IP 和端口。
4. 点击“连接老师端”。
5. 课堂中可以使用：
   - “举手提问”：需要老师点名或回答时点击。
   - “取消举手”：问题已解决或不需要发言时点击。
   - “可以继续”：表示当前进度可以继续。
   - “我没听懂”：表示当前内容没理解。
   - “讲慢一点”：提醒老师放慢节奏。
   - “请再讲一遍”：请求老师重复刚才内容。

## 互动频率限制

- 为了防止误点和刷屏，学生端对常用互动有短暂冷却提示。
- “举手提问”点击后 10 秒内不能重复提交；如果已经举手，会提示等待老师处理。
- 四个课堂反馈按钮共享 5 秒冷却，短时间重复点击不会反复刷新老师端提醒。
- “发送给老师”的不懂点提交有 30 秒冷却，避免连续上传截图让老师端卡顿。
- 冷却期间按钮会显示“请稍候 X 秒”；如果学生绕过界面连续发送，老师端也会拦截并返回中文提示。

## 截图上传

1. 先用 Windows 截图工具、QQ/微信截图等方式截好图。
2. 在学生端“不懂点”区域填写文字说明。
3. 点击“选择截图图片”选择本地图片，或复制截图后点击“粘贴截图”。
4. 确认预览无误后点击“发送给老师”。

当前只支持 `png`、`jpg`、`jpeg`、`webp` 图片。截图会自动压缩为 JPEG，最长边限制为 1600px，单次上传建议不超过 2MB。

## 老师回复

1. 老师在“问题收件箱”中双击某条问题。
2. 在详情窗口查看学生文字和截图。
3. 在“回复学生”中输入答案，点击“发送回复”。
4. 学生端会在“老师回复”区域看到答案。
5. 如果学生暂时离线，使用同一台电脑重新连接后会补收未读回复。

## 新班级清空与自动备份

- 换新班级时，老师端点击“新班级清空”。
- 系统会先把旧课堂记录自动备份为 zip，再清空当前课堂列表。
- 如果自动备份失败，系统不会清空旧课堂数据。
- 课堂名称和端口设置会保留，方便下一节课继续使用。

数据位置：

```text
data/class_sessions/<session_id>/
  events.jsonl
  uploads/
data/class_session_archives/
  <timestamp>-before-clear.zip
```

`events.jsonl` 保存课堂事件，`uploads/` 保存学生上传截图，`class_session_archives/` 保存清空前自动生成的归档备份。

## 防火墙与连接问题

如果学生端无法连接：

1. 确认老师端已经点击“启动课堂”。
2. 确认老师和学生电脑在同一局域网。
3. 学生端手动输入老师端显示的 IP 和端口。
4. Windows 防火墙弹窗出现时，选择允许专用网络访问。
5. 如果仍无法连接，请在老师电脑防火墙中允许 `教师端.exe` 的 TCP/UDP 局域网通信。

## 课堂流程建议

1. 上课前老师端启动课堂。
2. 学生端连接课堂，老师确认在线人数。
3. 讲课过程中，学生用“举手提问”和四个反馈按钮表达状态。
4. 老师看到匿名提醒后，可在管理界面查看具体学生并处理。
5. 学生遇到具体问题时，上传文字和截图。
6. 老师在问题详情中回复学生。
7. 换班级前点击“新班级清空”，确认自动备份生成。

## 教室试用检查清单

- 老师端能保存课堂名称和端口，重启后仍保留。
- 学生端能自动发现课堂；发现失败时可手动 IP 连接。
- 学生点击“举手提问”后，老师端顶部匿名提醒不显示姓名，举手队列能看到姓名。
- 学生点击“讲慢一点”后，老师端顶部匿名提醒不显示姓名，课堂提醒列表能看到姓名。
- 学生举手、重点反馈、提交不懂点后，老师端能看到匿名弹窗提醒，弹窗不显示学生姓名。
- 教师端和学生端重复打开时会提示禁止多开，不会出现两个主窗口。
- 学生能上传截图问题，老师端能查看缩略图和大图。
- 老师能回复学生，学生端能看到老师回复。
- 点击“新班级清空”后生成 zip 自动备份，并清空当前课堂数据。
